KG-XAI System Architecture

What was actually built and evaluated — not the proposal Static walkthrough — no model runs here

1 · Data flow and model pipeline

One shared encoder, two branches: a lesion-centered patch for segmentation, and a whole-brain view that feeds the knowledge graph. This replaced the originally proposed three-encoder, late-fusion design (not enough GPU memory or time to train it as specified) — disclosed, not hidden, in the paper.

Input — 6 channels

NCCT, CTA, CBF, CBV, MTT, Tmax · 1 mm isotropic · admission (session 1) only · 148 usable ISLES'24 subjects

Input — vessel mask

Admission Circle-of-Willis segmentation, used only to locate the 12 CoW vessel coordinates per patient

↓

Preprocessing

Resample to common grid · intensity normalize · crop 128×128×64 lesion-centered patch, in parallel with a fixed-size whole-brain view

↓

Shared SegResNet Encoder

ONE encoder, 6-channel input — not three per-modality encoders. Same weights process both the patch and the whole-brain view. Warm-started from a pretrained trunk.

↓

Patch branch → Decoder

Convolutional SegResNet decoder (not a Transformer) · cross-attention from the vessel graph injected at every stage · outputs the final infarct mask (binary — not core/penumbra)

Whole-brain branch

Trilinear sampling of stage-1 features at the patient's 12 real vessel coordinates

2 · Knowledge graph, layer 1 — vessel graph (feeds the GAT)

This is the only graph the learned pathway ever sees. It is patient-specific: coordinates and presence come from that patient's own CoW mask, not a population atlas.

12-node, 12-edge CoW graph

ICA, MCA, ACA, PCA, Acom, Pcom, BA (bilateral where applicable) · absent vessels = a flag, not a different edge set

2-layer GAT encoder

2 attention heads, ELU, dropout 0.2 · hidden size 32 · no pooling

12 vessel embeddings

One 32-dim vector per node, absent-vessel nodes masked out downstream

↓ cross-attention into every decoder stage, through a per-stage gate initialized to g = 0
verified byte-identical to the no-graph trunk at epoch 0 — the graph can only help through training, never silently break a working baseline

B1 = this pathway alone

Graph injection, no consistency loss

B2 = B1 + consistency loss

Adds the laterality loss below, trained on the whole-brain branch's coarse segmentation

4 · Rule evaluator — runs on every prediction, no ground truth needed at inference

Predicted mask + admission occlusion side

Both available at inference time, before any outcome is known

Hard laterality check

>50% of predicted lesion mass on the wrong side = inconsistent

↓

JDCR

Joint-Decision Consistency Rate: % of evaluable subjects that are laterality-consistent

Template rationale

Deterministic sentence from computed numbers — no LLM, no "activated concepts"

Triage flag

Laterality-inconsistent OR predicted volume < 1 mL — both computable with zero ground truth

5 · Disclosed negative result — auxiliary heads

LVO localization (4-class) + collateral grading (4-bin HIR proxy)

Tried under 4 independent regimes — pooled-feature heads, per-vessel GNN heads, GNN + augmentation, and a frozen-encoder ablation that rules out gradient competition. All four collapse to predicting one constant class for every patient. Diagnosed as a data-scale ceiling at 98 training patients with imbalanced classes and no true (non-proxy) collateral label — not an architecture or wiring bug. Not part of the working pipeline; kept out of the outputs above rather than reported as if functional.

7 · Where the graph does add value — failure detection, benchmarked

Not the learned pathway — the same graph used as a non-learned, ground-truth-free consistency check, compared head-to-head against two standard uncertainty-estimation baselines on the same predictions.

Honest nuance: MC-dropout is competitive or better specifically on subtler, non-catastrophic failures, on its own smaller subset. Read together, the knowledge flag dominates on catastrophic, structurally unambiguous failures — which is also where a silent miss is most costly in a deployed clinical system — not categorically on every kind of uncertainty.
