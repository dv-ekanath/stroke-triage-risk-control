The rationale is assembled from computed numbers only — no language model. The rule checked is the one plausibility rule that held up in real data: the infarct should sit on the same side as the blocked vessel (94.7% in ISLES'24, so it's a soft rule, not an absolute one).
These patients were held out: none of these five models trained on them (fold 0 validation set, 50 patients). The "collapsed run" is a real Phase 8 training failure kept on purpose — the plain baseline trained from scratch predicted no lesion at all in 2 of 9 runs; the graph-injected models never did in 12. That difference is confounded with warm-starting, and the graph did not significantly change Dice (p = 0.24). See PROGRESS_REPORT.md §6a.

Two additions since then, both run live here, not precomputed: the B0 ensemble averages all 3 of B0's seeds' probabilities with no retraining, and nearly closes the collapse gap on its own (outputs/tables/ensemble_check.json). The flagged for review badge uses only the two signals genuinely computable without ground truth (laterality, predicted volume) — flagged predictions score far worse in every model type, including B1 and B2, which never collapsed (outputs/tables/triage_check.json, §6b).
